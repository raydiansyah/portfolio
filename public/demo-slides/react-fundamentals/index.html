React
Fundamentals

Komponen, props, state, dan effect: empat ide yang membentuk hampir semua aplikasi React.

01 · Komponen

UI adalah fungsi dari data

Komponen adalah fungsi biasa yang mengembalikan JSX. Kecil, bisa dipakai ulang, dan mudah diuji.

function Greeting() {
  return <h1>Halo, kelas!</h1>
}
02 · Props

Data mengalir ke bawah

  • Props adalah argumen komponen, bersifat read-only.
  • Induk menentukan, anak menampilkan.
  • Komposisi lewat children, bukan pewarisan.
03 · State

Memori milik komponen

const [count, setCount] = useState(0)
<button onClick={() => setCount(c => c + 1)}>
  Diklik {count}x
</button>

Mengubah state memicu render ulang. Jangan mutasi langsung.

04 · Effect

Sinkron dengan dunia luar

  • useEffect untuk langganan, timer, dan API browser.
  • Selalu kembalikan fungsi cleanup.
  • Data turunan? Hitung saat render, bukan di effect.
Penutup

Latihan minggu ini

Bangun daftar tugas dengan komponen, props, dan state. Simpan ke localStorage dengan satu effect.
